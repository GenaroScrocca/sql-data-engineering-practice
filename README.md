# SQL Data Engineering Practice

Collection of SQL scripts demonstrating common data engineering concepts
related to data engineering such as SCD and data cleaning.

## Contents

### Slowly Changing Dimensions (SCD)
Example implementation of:
- SCD Type 1
- SCD Type 2
- SCD Type 3

Concepts used:
- MERGE
- staging tables
- historical tracking

### Removing Duplicate Rows
Example of detecting and removing duplicates using:

- ROW_NUMBER()
- PARTITION BY
- Common Table Expressions (CTE)

## Technologies
- SQL Server
- Data Warehousing concepts
